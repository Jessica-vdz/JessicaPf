# Jessica Portfolio

## About the Project

This portfolio is a project I worked on to showcase my work, skills, and experience as a developer. The goal of this project was to create a personal website where I can present my projects and show what I have learned during my development journey.

I worked on building the portfolio website and organizing the content to make my projects easy to explore. This project also gave me the opportunity to improve my web development skills and create a place where I can showcase my work.

## Features

- **Project Showcase:** Displaying projects I have worked on.
- **Personal Portfolio:** Presenting my skills and development experience.
- **Website Design:** Creating a clear and accessible user interface.
- **Project Overview:** Providing an overview of my work and learning experiences.

- **CSS** — Styling the layout and design.
- **JavaScript** — Adding interactive functionality.
